# Portfolio assets

This folder holds the local image and document files used by the portfolio. Keep the filenames stable unless you also update their references in `index.html` and the social metadata.

## Files

- `hans-soni.png` — Main profile portrait displayed in the hero section as a circular image.
- `Hans_Soni_Resume.pdf` — Downloadable resume. Linked from the navigation and hero actions.
- `og-preview.jpg` — Social preview image referenced by the Open Graph metadata when the portfolio URL is shared.
- `README.md` — This asset inventory and usage guide.

All three assets are served locally with the static site; no image hosting service is needed for these page elements.
